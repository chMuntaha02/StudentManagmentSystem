# Student Course Enrollment System

### Project Structure (Packages)
- student - Student.java
- course - Course.java
- payment - PaymentMethod (Interface), CreditCardPayment, PayPalPayment
- enrollment - EnrollmentService
- main - Main.java

### How to Run
1. In VS Code or Eclipse, make a new Java Project
2. Copy src folders
3. Run main.Main.java

### Concepts Used
Encapsulation, Interface, Polymorphism, Package Structure
